# 🌿 WILD EARTH – Wildlife Conservation Website

## Introduction
WILD EARTH is a website based on wildlife and nature conservation. It aims to spread awareness about endangered animals, environmental problems, and the importance of protecting nature.

The website presents information in a simple and visually appealing way using images, text, and a wildlife video.

## Website Sections

1. **Home:** Introduces the website with a background image and a conservation message.
2. **Wildlife:** Displays different animals, including the Bengal Tiger, Asian Elephant, and Sea Turtle.
3. **Nature in Motion:** Features a video related to wildlife.
4. **Environmental Threats:** Highlights deforestation, pollution, and poaching.
5. **Take Action:** Suggests everyday activities that can help protect the environment.
6. **About:** Explains the purpose of WILD EARTH.
7. **Footer:** Provides links to important sections of the website.

## Tools and Technologies
- **HTML5:** Used to build the webpage structure.
- **CSS3:** Used to style the page, arrange content, and improve its appearance.
- **VS Code:** Used to write and edit the code.

## How to Open the Website
1. Open the project folder in Visual Studio Code.
2. Check that all images and video files are in their correct folders.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension to run the website.
